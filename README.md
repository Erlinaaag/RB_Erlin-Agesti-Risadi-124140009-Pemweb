# Tugas 3 Pemrograman Web

## Form Pendaftaran Mahasiswa

Project ini merupakan tugas Pemrograman Web sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

Website terdiri dari dua halaman, yaitu halaman form pendaftaran dan halaman detail pendaftar. Data yang dimasukkan pada form dikirim menggunakan method `GET` dan ditampilkan pada halaman detail berdasarkan query string.
